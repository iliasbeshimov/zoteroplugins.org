Many plugins are built with zotero-plugin-toolkit, and most of them add two zotero:// links to Zotero. One installs a plugin from any address in the link, without Zotero asking you first. The other runs code from the link; current versions ask you first. Web pages and documents can open zotero:// links, and a plugin can do anything Zotero can. Both links are blocked, and a short notice appears if one is used. One-click "install" links on websites won't work; install plugins from Tools → Plugins instead. This plugin does nothing. If your other plugins added these links, a link can again install a plugin without asking you. This plugin's code makes no network requests, and it stores only this setting. Zotero checks GitHub for updates to it, as it does for other plugins.
