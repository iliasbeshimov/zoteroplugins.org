Find and install plugins from zoteroplugins.org inside Zotero, filtered to your Zotero version, with each plugin's grade. It also watches the plugins you have: it tells you when one drops a grade, when the update Zotero would apply is graded worse, when Zotero's blocklist blocks it, or when Zotero has disabled it because it doesn't work with your version. Open it from Tools → Zotero Atlas.
