Privacy

What the plugin sends, what it never sends, what the server keeps, and how to stop. Written to be checked against the code: the plugin is in src/, the server in server/.

Zotero Atlas never sends your library, notes, files, Zotero account, email or anything that identifies you.

The one thing it can send

The first time it runs it asks one question, with Send my plugin list as the default answer and Don't send one click away. With Send my plugin list, it sends one message to zoteroatlas.com:

{
  "id": "4c9d3b2e-…",          a random ID made on this computer
  "atlas": "0.1.0",            this plugin's version
  "zotero": "7.0.32",          your Zotero version
  "os": "mac",                 "mac", "windows" or "linux"
  "event": "weekly",           "first-run", "changed" or "weekly"
  "plugins": [                 every plugin installed in this Zotero
    { "id": "zoterostyle@polygon.org", "version": "5.0.0", "enabled": true },
    …
  ]
}

It is sent when you turn the choice on, when the list of plugins changes, and once a week. The ID is a random UUID the plugin generates on your computer; it is not derived from your hardware, your Zotero account or anything else, and it is the only thing that links one report to the next. Show what would be sent, in Zotero's settings under Zotero Atlas, shows your exact message.

Ratings and reviews

Nothing is sent until you click Post on a rating. Then it sends the plugin and version you rate, your stars and your review if you wrote one, your Zotero version and operating system, this plugin's version, and a scrambled ID for this Zotero, so rating again replaces your rating. That ID is a slow hash of a random key Zotero makes for its database; the key itself is never sent, and nothing is stored on your computer for it. While Send my plugin list is chosen, the rating also carries that list's random ID, so the rating can say how long you had the plugin.

Reviews are public, shown as "Zotero Atlas user" with your Zotero version. Links are removed. We never store your IP address. For ratings, the server keeps a scrambled code made from it, and the name of your network's operator, for 30 days to catch fake reviews. The code is made with a secret key that's replaced every month; after 30 days the code is cleared and its key deleted, and even we can't match it to anything. Every rating is checked before it's published; how fake ones are spotted isn't published, so it can't be gamed.

You can also review plugins on zoteroplugins.org, with an email address that you confirm by a link. The address is never shown and never stored: it's used to send the link, and we keep only a fingerprint of it, so one address gets one review per plugin. The service that delivers the email sees the address, as any mail service does.

What the server keeps

Per reporting install: the random ID, the Zotero version, the operating system, the plugin's version, and the plugin list, replaced on every report, except that a plugin you remove is remembered for 30 days so a rating can say how long it was used; and the date of every report with its reason (first run, list changed, weekly). Nothing else from the request is kept: no IP address, no user agent, no headers. A nightly job deletes all of it for an install not heard from for 180 days. Choosing Don't send deletes it at once; your ratings stay, without the link to your plugin list.

Cloudflare, which runs the server, sees requests the way any web host does. We keep none of that, and the server code that decides what is stored is public.

None of it is published. It stays in the server's database, which only we can read, and we use it as counts: how many installs report, which plugins they have, and which Zotero versions and systems they run. That tells us which plugins people actually use.

Turning it off, and deleting your record

Open Zotero's settings, choose Zotero Atlas, and pick Don't send. The plugin then asks the server to delete everything it holds for its ID, report dates included, and stops sending. Uninstalling the plugin stops the sending and removes everything it stored on your computer, but doesn't contact the server: to delete your record, pick Don't send before you uninstall. Otherwise the server deletes it after 180 days without a report, as above.

What happens whatever you choose

  • Once a day the plugin fetches the directory's catalogue, a single public file, from raw.githubusercontent.com, the directory's repository on GitHub. The request carries no account and no identifier beyond what any download carries.
  • When you click Install, Zotero downloads the plugin's release file from GitHub, as it would for any plugin you install.
  • Zotero checks this project's GitHub releases for updates to Atlas itself, as it does for every plugin. You can turn that off per plugin in Tools → Plugins.
  • When you post a rating, it goes to zoteroatlas.com, as described above.
  • Nothing else is contacted.

What it stores on your computer

Three settings in Zotero's preferences (extensions.zotero-atlas.usage, .id, .state, which also remembers the ratings you posted and the plugins you removed in the last 30 days) and a copy of the catalogue at zotero-atlas/catalog.json in your Zotero data directory. Uninstalling removes all of it.

This website

The Zotero Atlas plugin never loads Google Analytics or anything else from Google. What follows is about the zoteroatlas.com website only.

In the European Economic Area, the UK and Switzerland, the website runs no analytics and loads nothing from Google unless you accept the question at the bottom of the page. Elsewhere it counts visits with Google Analytics unless you turn it off, and it stays off if your browser sends a Global Privacy Control signal. To tell which applies, the page asks Cloudflare, which hosts the site, for the country of your connection; only the country is used, and it isn't stored anywhere but your browser for the session.

When it's on, the website loads Google Analytics through Google Tag Manager. Google then gets your IP address, your browser and device, the page you came from, and the pages you view here, and sets its cookies (_ga). It tells us which pages people read and how they found the site. There are no accounts and no ads.

Your choice is kept in your browser's storage, not in a cookie. You can at any time; turning analytics off deletes Google's cookies.

Apart from that, the website loads nothing from third parties: the fonts are your system's, and everything else is served from here. The one image from elsewhere is the live grade badge, loaded from zoteroplugins.org, which we also run. Cloudflare sees requests the way any host does.
