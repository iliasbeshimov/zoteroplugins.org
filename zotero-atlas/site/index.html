Questions

Is it free?

Yes. Free and open source under the MIT licence.

Which Zotero versions does it work with?

Zotero 7 to 11, on Mac, Windows and Linux.

Where do the grades come from?

From zoteroplugins.org, the catalogue Atlas reads. It reads the code of every plugin's latest release, every night, with the same rules for every plugin. How plugins are graded

Will it change my plugins without asking?

No. At first run you choose whether Atlas may hold updates until they're checked. It turns a plugin off only when you click "Turn it off", and plugins the catalogue doesn't list are never held.

What does it send?

Never your library, notes, files, Zotero account or anything that identifies you. By default it sends the list of plugins you have, under a random ID, so we can see which plugins people use. "Don't send" is one click, any time. Full details
