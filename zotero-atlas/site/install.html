Something not working?

Zotero says the plugin isn't compatible

Zotero Atlas needs Zotero 7 or later. In Zotero, choose Help → Check for Updates, then install the file again.

There's no Plugins item in the Tools menu

That's Zotero 6 or older, where it was called Add-ons. Atlas needs Zotero 7 or later: update Zotero first.

Firefox or another app opened the file

The file is for Zotero. Close that app and install the file from Zotero, as in step 2.
